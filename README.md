# เข้าใจก่อนลงทุน

เว็บแอป PWA ภาษาไทยสำหรับเรียนรู้พื้นฐานการอ่านกราฟหุ้นและ Forex มีบทเรียน แบบทดสอบ กราฟจำลอง และเครื่องมือคำนวณเพื่อการศึกษา ไม่มีข้อมูลราคาตลาดจริงและไม่มีสัญญาณซื้อขาย

## เส้นทางหลักสูตร

- หลักสูตรเริ่มต้นแบบฟรี: 12 บท ครอบคลุมตลาด กราฟ อินดิเคเตอร์ ความเสี่ยง Forex และการฝึกทดสอบแนวคิด
- เส้นทาง Premium ที่อยู่ระหว่างจัดทำ 3 เส้นทาง ๆ ละ 6 บท พร้อมชิ้นงานฝึก: ลงทุนระยะยาวและกองทุน, อ่านกราฟเชิงลึก, Forex และการจัดการความเสี่ยง
- หน้า Premium ในปัจจุบันเป็นเพียงแผนหลักสูตร ยังไม่มีบัญชีสมาชิก การล็อกเนื้อหา หรือระบบชำระเงิน ห้ามใส่เนื้อหาที่ต้องปกป้องไว้ในไฟล์สาธารณะก่อนมีระบบสิทธิ์เข้าถึงฝั่งเซิร์ฟเวอร์

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository และอัปโหลดไฟล์ในโฟลเดอร์นี้ โดยใช้ branch `main`
2. เปิด **Settings → Pages** แล้วเลือก **GitHub Actions** เป็นแหล่งเผยแพร่
3. รอ workflow ชื่อ **Publish static PWA to GitHub Pages** ทำงานสำเร็จ จากนั้นใช้ URL ที่แสดงในหน้า Pages

Workflow จะนำไฟล์แอปและไอคอน PNG สำหรับ Android/iOS ขึ้นเว็บไซต์โดยตรง ไม่ต้องติดตั้งแพ็กเกจหรือ build ก่อน

เมื่อได้ URL HTTPS แล้ว เปิดบนมือถือเพื่อเพิ่มไปยังหน้าจอหลัก: Android ใช้ Chrome; iPhone ใช้ Safari แล้วเลือก **เพิ่มไปยังหน้าจอโฮม**

## แอป Android สำหรับติดตั้งทดลอง

โฟลเดอร์ `android/` เป็นแอป Android ที่เปิดเว็บแอปบนโดเมน GitHub Pages เดิม ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดเนื้อหาล่าสุด

1. ทุกครั้งที่มีการเปลี่ยนแปลงใน `android/` workflow **Build Android APK** จะสร้าง APK สำหรับติดตั้งทดลอง
2. เปิดแท็บ **Actions** ใน repository แล้วเลือก run ล่าสุดของ **Build Android APK**
3. ดาวน์โหลด artifact ชื่อ `khao-jai-kon-longthun-android-apk` แล้วติดตั้ง `app-debug.apk` บน Android

APK นี้ลงนามด้วยกุญแจ debug สำหรับทดสอบเท่านั้น ยังไม่ใช่ไฟล์ release สำหรับ Google Play การเผยแพร่ใน Play Store ต้องตั้ง package ID และ signing key สำหรับ release ก่อน

## ไฟล์หลัก

- `index.html` — เนื้อหา แอป และเครื่องมือ
- `manifest.webmanifest` — ชื่อและการตั้งค่า PWA
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — ไอคอนติดตั้งสำหรับ Android และ iOS
- `sw.js` — cache สำหรับเปิดใช้งานแบบออฟไลน์
- `.github/workflows/pages.yml` — workflow เผยแพร่ GitHub Pages

เนื้อหาเป็นความรู้ทั่วไปและตัวอย่างจำลอง ไม่ใช่คำแนะนำการลงทุน
